# Git Çalışmaları ve Pratik Laboratuvarı 🚀

Bu repository, versiyon kontrol sistemleri (Git) üzerindeki ileri düzey senaryoları öğrenmek, pratik yapmak ve kriz yönetimi becerilerini geliştirmek amacıyla oluşturulmuştur.

### İçerilen Senaryolar ve Uygulamalar:
- **Rebase & Squash:** Dağınık commit geçmişini tek çatı altında birleştirme.
- **Security (.gitignore):** Hassas dosyaları (`.env`) geçmişten temizleme ve koruma altına alma.
- **Merge Conflict:** İki farklı daldaki çakışmaları manuel ve görsel olarak çözme.
- **Git Bisect:** İkili arama (binary search) mantığıyla hatalı commit'i nokta atışı bulma.
